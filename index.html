JavaScript

Fetch API

A clean way to make asynchronous HTTP requests in the browser.

fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));

Local Storage

Save user data persistently on the client side easily.

// Save data
localStorage.setItem('username', 'Alice');

// Retrieve data
let user = localStorage.getItem('username');

CSS Tricks

Flexbox Center

The easiest way to horizontally and vertically center an element.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}

Dark Mode Root

Define global variables to swap color schemes instantly.

:root {
  --bg: #ffffff;
  --text: #000000;
}
[data-theme="dark"] {
  --bg: #000000;
  --text: #ffffff;
}

Python

Read CSV File

Quickly parse comma-separated values using the built-in module.

import csv

with open('data.csv', mode='r') as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)

Basic HTTP Server

Spin up a quick local web server straight from the terminal module.

# Run this in your command line
python3 -m http.server 8000
